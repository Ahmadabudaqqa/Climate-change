# Repository Contents

This repository contains two projects:

## 1. Climate Change Analysis (SDG13)

Our Project is about how Machine learning can support one of the United Nations' Sustainable Development Goals (SDGs). The goal is to apply machine learning techniques to analyze and derive meaningful insights from real-world data, while gaining hands-on experience in data preprocessing, model building, and hyperparameter tuning.

### About the Climate Project
- **Topic**: Climate Action (SDG13)
- **Focus**: Climate Change in Pakistan from 1901 to 2016
- **Data**: Historical rainfall data (included in repository)
- **Analysis**: Rainfall trends, climate challenges, and mitigation strategies
- **Models**: Multiple machine learning models to predict rainfall and classify it into categories (above or below average)
- **Contributors**: 
  - Ahmad Abu Daqqa: Data preprocessing
  - Selim Elhady: Machine learning models implementation

From 1901 to 2016, Pakistan has undergone periodic fluctuations in annual rainfall, which have been further exacerbated by the effects of climate change. This proposal examines the historical rainfall trends, identifies the challenges posed by climate change, and proposes actionable strategies to mitigate associated problems.

## 2. Robot with HC-020K Encoders

🤖 **NEW**: Arduino-based obstacle avoidance robot with encoder support for improved movement stability.

### Code Location
- **Main Code**: [robot_with_encoders/robot_with_encoders.ino](robot_with_encoders/robot_with_encoders.ino)

### Wiring (Quick Reference)
```
Left Encoder:  VCC→5V, GND→GND, OUT→Pin 2
Right Encoder: VCC→5V, GND→GND, OUT→Pin 3
L298N: Same as your original robot
IR Sensor: A0 (same as original)
```

### Features
- IR obstacle detection and avoidance
- Encoder-based speed stabilization for straight movement
- 80-90% better straight-line accuracy
